### ご挨拶(greeting.html) — パンフレット「ご支援のお願い」より

一般財団法人 北九州教育財団 理事長 上田 隆雄

- 財団は北九州市内のすべての子どもたちの健やかな成長と、未来を切り拓く力を育むために設立
- 前身は「PTA基金」。2019年に一般財団法人として組織化
- 課題: いじめ・不登校・ネットトラブル・家庭環境の変化など。学校だけでなく家庭・地域が協働して支える仕組みが必要
- 研修・講演会・学校支援を通じて、地域全体で子どもを育てる基盤づくりを進める
- 「子どもたちの未来を創るための土台」をつくる

### 主な取り組み(activation.html など) — パンフレットより

1. **単位PTA活動活性化推進事業**
   各学校のPTAが取り組む「いじめ防止」「ネットリテラシー向上」「不登校支援」「家庭学習習慣づくり」などの活動に助成金を交付
2. **子どもへの直接支援**
   - 北九州市立子ども図書館へ電子書籍を寄贈(累計80冊)
   - コロナ禍にマスク4万枚を市内全小中学校へ寄贈
   - 教育環境改善・ICT環境整備への支援
3. **教育講演会・研修会の開催**
   教育DX、いじめ・不登校支援、子ども政策など。行政(教育委員会・子ども家庭局)との共催、教育専門家・大学教授の登壇、PTA役員や保護者が参加できる学びの場

### ご寄付について(donation.html) — パンフレットより

キャッチ: 「子どもたちの笑顔は、地域の未来をつくる」「教育を支えるのは、あなたの力です」

| | 寄付 | 協賛 |
| --- | --- | --- |
| 対象 | 個人・法人・個人事業者 | 法人・個人事業者 |
| 金額 | 1口 2,000円から | 1口 10,000円から |
| 返礼 | ホームページに芳名掲載 | ホームページに芳名掲載 |
| 受付期間 | 随時 | 随時 |

寄付・協賛の流れ: 1. お申込(申込用紙またはWEBフォーム) → 2. ご入金(郵便振替) → 3. 証明書送付(寄付金受領証明書を郵送またはメール)

寄付の使途(例): 10,000円 講演会の資料印刷費・運営費 / 30,000円 1校のPTA活動をサポート / 100,000円 子ども電子図書館への電子書籍購入 / 300,000円 教育講演会の開催費用の一部

協賛企業様へのメリット: 財団HPへの企業名掲載、講演会会場およびパンフレットへの社名掲出、CSR活動として広報可能、SDGs(4「質の高い教育をみんなに」)への貢献

遺贈: 子どもたちの未来のための「遺贈」の相談を随時受付
