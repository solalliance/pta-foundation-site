## 作業ルール(必ず守る)

1. **法人名の表記**: タイトル・フッター・コピーライトは「一般財団法人 北九州教育財団」、本文中は「北九州教育財団」。旧名称「北九州市PTA協議会教育財団」は使わない。
2. **noindex**: 全ページの `<head>` に `<meta name="robots" content="noindex, nofollow">` を入れる(index.html からコピー)。公開時に一括で外します。
3. **キャッシュ対策**: CSS / JS を変更したらコミット前に `sh tools/bump-cache.sh` を実行(全 HTML の `?v=` が更新される)。HTML だけの変更なら不要。
4. **共通パーツ**: ヘッダー・ドロワーナビ・フッター・`<script>` は index.html からそのままコピー。ナビの `href="#hero"` は下層では `index.html` に直す。
5. **ヘッダーの見え方**: ヘッダーはトップのヒーロー用に「最上部では透明＋白ロゴ」になっています(`js/main.js` の `updateHeaderOnScroll`)。下層ページでは最上部に色付き/写真のページタイトル帯(page hero)を置くか、`<body class="page-sub">` を付けて CSS で常に白背景＋黒ロゴにするなど、白ロゴが背景に溶けないよう対応してください(どちらの方式でも可)。
6. **(案)の情報**: 名簿・活動報告・事業計画は「(案)」です。ページは作って良いですが、確定版が来たら差し替える前提でコメントを残しておいてください。
7. **写真**: 各ページ用の写真は未支給。`images/dummy.jpg` などで仮置きし、差し替え箇所に `<!-- TODO: 写真差し替え -->` を入れてください。
